

# Wallapp Android

[![F-Droid](https://img.shields.io/f-droid/v/com.debojit.wallapp.svg)](https://f-droid.org/packages/com.debojit.wallapp/)
[![License](https://img.shields.io/github/license/debojitsantra/Wallapp-Android)](LICENSE)
![Maintenance](https://img.shields.io/badge/maintenance-temporarily_paused-orange)

**Wallapp Android** is a lightweight Android wrapper for **TheWallApp**, a wallpaper platform for browsing and downloading wallpapers.

The app loads the website inside a native **Android WebView** and extends it with native Android capabilities such as **setting wallpapers directly from the app**.

Website: https://thewallapp.pages.dev

---

## Features

- Browse wallpapers from **TheWallApp**
- Lightweight Android WebView wrapper
- Set wallpapers directly from the app
- Minimal UI

## Installation

### F-Droid

You can install the app from F-Droid.

[<img src="https://f-droid.org/badge/get-it-on.png"
    alt="Get it on F-Droid"
    height="80">](https://f-droid.org/packages/com.debojit.wallapp)
    
## Build from Source

```bash
git clone https://github.com/debojitsantra/Wallapp-Android.git
cd Wallapp-Android
./gradlew assembleDebug
```
The APK will be generated in:
```bash
app/build/outputs/apk/debug/
```
You can also open the project directly in Android Studio if preferred.
